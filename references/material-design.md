# 素材与视觉规则

## 默认视觉基准

默认方向：清透的浅色底子，随性、有一点古怪可爱的手绘和纹样，便于自由拼贴和继续写字。这里记录的是此用户的盐系偏好，不是对所有盐系的统一定义。

生成前阅读 [视觉参考索引](visual-references.md)，查看手绘主参考与一个适合当前主题的色彩/晕染参考。用户未指定配色、要求更好看的颜色组合或连续生成多套时，再阅读 [配色方法与种子色板](palette-recipes.md)，选择并变形一种颜色关系，避免连续复用。旧 [微加深样张](visual-baseline.png)仅用于比较浅色的可辨识程度；其彩铅排线、巨大书写区和版式不再作为默认画法。参考只约束气质，不复制图案、文案、配色方案或布局。
- 大面积近白，可带浅蓝、淡粉、奶黄、嫩绿、灰紫。色系是主色倾向，不是只准两种颜色；辅助色、物件本色和少量强调色可以共存。不要每套沿用蓝黄绿。
- 每套先建立颜色层级，而不是让每件素材各占一种颜色。通常选择约三种反复出现的主彩色家族，让它们跨纸张、胶带和小图重复呼应；再用纸白、奶油色、燕麦色或浅灰等中性色承接。可以另有一种只占极小面积的强调色或深色锚点。数量可随主题变化，不机械锁死为三种，但要让人一眼看出哪些颜色在统领整套。
- 三种主色也不应平均分地盘。选择一个承担较多面积的主导色，另外一至两种作为支持色穿插重复；强调色只落在圆点、短线、小标签或物件细节中。单张后续拼贴不必同时等量使用整套所有主色。
- 多色不等于把蓝、粉、绿、黄、紫分别铺成五块同等醒目的大纸。若每张基础纸都是不同色且没有重复呼应，先合并相近色或把部分纸退回中性色，再保留少量异色小点。
- 底纸保持轻浅，格线、波点、英文和小图比底纸略清晰。少量较深色有作用即可，不强制黑色、藏青或深棕来建立对比，也不把全部细节淡到不可辨认。
- 手绘的自然笨拙来自略歪的比例、不完全对称、轻重变化的线条、少量断笔和未涂满的色块。用几笔认出物件即可；不要把标准矢量图标叠纸纹当作手绘，不刻意乱抖或画成模糊污迹。
- 手绘以用户最新图4为主：随手流动的单线、歪一点的轮廓、憨拙或略有想象力的形状；线描、空心形与柔和平涂色块可以同套共存。颜色薄而干净，保留轻微不均匀；不要默认彩铅排线、反复刮擦、标准几何图标或完整明暗塑形。平涂不等于矢量化、绝对对称和机械光滑。
- 具象小物默认不做成统一刀模贴纸：不在电脑、杯子、夹子、花朵等每个物件外侧套同宽白边，也不用深色粗线把所有轮廓完整封闭。优先直接沿柔和平涂色块剪形，或只留少量浅色、断续、未闭合的结构线；闭合描边应是个别画法选择，不能成为整套统一效果。
- 简化不等于卡通图标化。减少键盘格、杯沿阴影、表情和装饰细节，让物件保留一点歪斜、空缺和手工感；若多个具象物放在一起像一组角色贴纸，应进一步缩小、减线或改为剪影、小图卡与局部轮廓。
- 纸面大多干净，纹理轻微且局部化；避免均匀厚颗粒、满页水彩斑驳、牛皮纸泛黄和厚白边阴影。
- 允许局部渐变、柔边晕染、淡色光晕或色团：例如颜色淡向纸白的果实、轻微扩散的波点、朦胧线圈。与清晰的细线和纹样搭配，保留清柔变化，不全页模糊，不每件加渐变或立体光泽。参考照片的柔焦、曝光和压缩不是都要复制的设计效果。
- 细格、小点、小花、细条纹可有疏密差异，写上字后能退到背景。白底与浅色块并用，不需要每张纸满铺颜色。

## 贴纸选题与主题关系

日记主题优先决定整套的情绪、颜色、轻重与节奏，不要求把句子中的每个名词变成贴纸。用户提到健身、上班、搬家、咖啡或下雨时，不自动生成背包、鞋、电脑、钥匙、咖啡杯或雨伞的物品清单。直接对应主题的具象锚点通常控制在零至一个；只有用户明确点名、物件本身足够好看，或经过高度概括后确有构图价值时才使用。

贴纸主体默认以“装饰性联想”而非“事件说明”为目标。可以从以下语言中选择并组合：

- 植物、花朵、叶片、枝条、果实等泛自然母题；
- 星芒、波浪、雨滴、火花、括号、短线、环形节奏等抽象符号；
- 花瓶、杯子、镜子、餐具、蝴蝶结、容器等经过强烈简化的泛生活物件；
- 略带想象力的小生物、剪影或憨拙形象，但不做成表情包和成套漫画角色；
- 两三种母题组成的小型寓意画面，例如花与星、容器与枝叶、波浪与剪影，不追求现实场景完整。

这些元素可以与主题只有松散的情绪联系。比如“周一低落、晚上健身”可以转译为弯曲线条、低垂花枝、向上星芒、舒展的蝴蝶结或一组有节奏的抽象符号，而不必出现运动装备。让贴纸负责增添诗意、可爱感和画面节奏，纸张与用户书写负责记录具体事件。

贴纸不只是一枚孤立物件，也可以是一块小色面里的微型构图：方形、圆形、椭圆、窄条或自由轮廓中放置两三枚线描或平涂母题，利用重复、留白和正负形形成图案感。此类“图案贴纸”与单独轮廓剪贴可以同套共存。避免把一个大而写实的物件当作主贴纸，也避免因主题包含多个动作就制作多件对应物品。

选题前先看近期输出：若最近几套频繁出现杯子、包、云朵、圆点或蝴蝶结，本套优先换用其他母题。变化来自母题组合、轮廓形式和图案关系，不仅是换颜色。

## 素材角色与尺度

| 角色 | 可用内容 | 选择标准 |
|---|---|---|
| 基础纸 | 长方形、正方形纯色纸，细格、条纹、波点、轻纹样纸 | 主要面积，纸本身就能写字或裁成垫纸 |
| 轻装饰便签 | 纸角的一盏小灯、小凳子，底部几条浅线或小色块 | 装饰占比小，大部分可写；不是每张都装饰 |
| 造型书写纸 | 对话框、略不规则椭圆、圆形、自由轮廓色块 | 内部安静，边框细或省略；不固定巨大中央便签 |
| 主题小素材 | 通常1–2个装饰性母题组合、轮廓剪贴、剪影或小图卡 | 比基础纸明显小；默认松散呼应情绪，不逐字图解日记，也不让两个大插画争主体 |
| 连接点缀 | 小卡子贴、回形针、胶带、长短宽窄不同的纸条 | 能跨纸边或连接局部，不预先贴到独立基础纸上 |
| 自由小点缀 | 可爱小元素、手绘曲线、蝴蝶结、圆点、星星、小花、雨滴、短线、小色块等 | 每套只选一至两类主要点缀语言，并随主题与近期输出轮换；不默认总有圆点，也不固定圆点＋星星组合 |
| 文字点缀 | 简短英文词组、小标签、印章感字样 | 可选、少量、自然准确；不代写标题正文 |
| 可选日期 | 手写数字、描边数字、小日期签 | 用户提供或明确要求时添加 |

专门书写区默认克制：可先安排一块中等书写纸，其余以小纸块、窄条和点缀搭配，也可完全不设专用便签。不要把所有浅色纸都放大成待填满的区域；大面积留白也可以在纸间自然出现。写字多时按用户需求调整，不以固定行数限制所有主题。纸张总面积可主导，但不等于巨型书写框。

留白是素材体系的一部分，不是排完物件后剩下的边框。素材页要有连续、宽松的空白通道穿过物件之间，至少让部分小元素周围保持安静；不要为了“利用画布”放大便签、底纸或主题图像。若所有空白都被压成等宽裁切缝，或只剩页面四周一圈，说明密度偏高。

自由小点缀要作为真正可用的独立素材：尺寸虽小但应清楚可见、便于单独裁切，通常接近窄胶带宽度或其他微型贴纸的视觉重量。同一套里不必把圆点、星星、蝴蝶结、小花和雨滴都放齐；根据情绪选择一至两类，再用一条曲线、短线或小色块补节奏。多个同类点缀之间留足裁切距离，不排成过小的一行色卡；颜色可以来自辅助色或强调色，为后续分散呼应准备。若最近几套都使用了圆点，下一套优先换成星点、小花、雨滴、短线或小色块，除非圆点确实最符合主题。

类别按主题选择，总数不固定，不机械沿用11/12/13件。主题图像保持点题作用，纸张、文字空间和点缀各有分量。小图可先按主要纸张宽度约四分之一到三分之一规划，实际根据形状调整；不把目标比例当作已验证尺寸。

细长或内部留白多的轮廓图像可以较长，如叉子、雨伞、花枝；不能把“小贴纸”误解为全部同样矮小。保持视觉重量轻，且缩小后仍可剪、可识别。不要在拼贴阶段才擅自放大它。

## 完整素材与裁剪

基础纸默认完整直边、完整矩形/方形，无预制撕边、破角、折角或做旧；用户打印后自行裁撕。对话框和异形纸是有意设计的平滑外形，可以保留。

轮廓剪贴与撕纸不同：可提供沿物件外形裁剪的小图，或给简单小图卡保留充足外缘，方便用户把其中物件单独剪出。轮廓应清楚，避免过细复杂的突出部位，不强制所有图像都有厚白边。若是便签上的一体小插画，清单注明其属于该纸，不另计一个独立贴纸。

## 输出检查

- 纸张主导面积、主题小图克制，细线和小图辨识清楚，保留写字空间。
- 素材完整分离，有裁切间距；基本纸无预制撕边；没有默认大标题或正文。
- 颜色丰富但轻浅，手绘自然，局部晕染不牺牲辨识；专用书写区不过大，小素材不因空位而被放大。
- 具象小物没有统一白色刀模边和成套粗描边；完整图标数量少、视觉重量轻。
- 有连续的有效留白进入素材之间，而非只有外边距和狭窄裁切缝。
- 约三种主彩色家族在不同素材类别中重复出现，并有清楚的主导色与支持色；中性色承接大面积，强调色只占很小部分。没有每张大纸各占一种无呼应颜色的情况。
- 微型点缀清楚、可裁切，不缩成一排色卡；点缀类别与近期输出有变化，不把圆点当作每套必备项。
- 不因“打印可能偏淡”未经试印就大幅加深。
- 所有材料都进入一张后续拼贴仍可形成主次；必要时生成前减少数量。
- 新参考用于学习颜色、画法、形状和拼贴关系，不复制签名、水印、文案或品牌。
